  • Viết tất cả trong một file.

08. Thực hành Component

Tách UI thành nhiều component nhỏ

Đây là phần quan trọng nhất của React. Học viên cần hiểu tư duy: "UI lớn = ghép từ nhiều component nhỏ" .

1. SiteHeader

Component header dùng để hiển thị phần đầu website. Đây là component có thể tái sử dụng cho nhiều page. 

export function SiteHeader() {
  return (
    <header className="w-full h-16 flex items-center justify-center bg-zinc-50 dark:bg-black">
      <h1 className="text-xl font-bold text-black dark:text-zinc-50">
        Site Header
      </h1>
    </header>
  );
}

2. HeroSection

Hero section là phần nổi bật đầu trang. Thường chứa slogan, CTA hoặc banner chính. 

export function HeroSection() {

  return (

   <section className="w-full h-96 flex items-center justify-center bg-zinc-50 dark:bg-black">

     <h1 className="text-4xl font-bold text-black dark:text-zinc-50">

       Hero Section

     </h1>

   </section>

  );

}

Ghép nhiều component lại để tạo thành page hoàn chỉnh.

14. Next.js Image Component

Hiển thị ảnh trong Next.js

Trong Next.js, cách hiển thị ảnh phụ thuộc vào vị trí lưu ảnh. Có 2 cách phổ biến: dùng thư mục public hoặc import ảnh từ src/assets.

1. Ảnh trong thư mục public

Đây là cách phổ biến nhất trong Next.js. Ảnh đặt trong public sẽ được truy cập trực tiếp bằng URL. 

public/
  assets/
    logo.png

Dùng với thẻ img: 

export default function Home() {
  return (
    <img
      src="/assets/logo.png"
      alt="Logo"
    />
  );
}

Dùng next/image với public

next/image giúp tối ưu hình ảnh, lazy loading và responsive tự động. 

import Image from "next/image";

export default function Home() {
  return (
    <Image
      src="/assets/logo.png"
      alt="Logo"
      width={200}
      height={200}
    />
  );
}

2. Ảnh trong src/assets

Khi muốn import ảnh như module JavaScript, có thể để ảnh trong src/assets. 

src/
  assets/
    logo.png

  app/
    page.jsx

Import ảnh bằng module

import Image from "next/image";
import logo from "@/assets/logo.png";

export default function Home() {
  return (
    <Image
      src={logo}
      alt="Logo"
      width={200}
      height={200}
    />
  );
}

Dùng img với ảnh import

Có thể lấy đường dẫn thật của ảnh bằng logo.src 

import logo from "@/assets/logo.png";

export default function Home() {
  return (
    <img
      src={logo.src}
      alt="Logo"
    />
  );
}

Nên dùng cách nào?

  • Logo, banner, icon tĩnh → dùng public/assets
  • Muốn import như module → dùng src/assets
  • next/image là lựa chọn tốt nhất cho performance
  • Không viết: /public/assets/logo.png
  • Đúng phải là: /assets/logo.png

Ví dụ chuẩn với public

<Image
  src="/assets/logo.png"
  alt="Logo"
  width={200}
  height={200}
/>

Vì sao Next.js dùng public?

  • Đơn giản và dễ quản lý ảnh
  • URL ngắn gọn
  • Tối ưu cho static assets
  • Dễ deploy production
  • Học viên mới dễ hiểu hơn

Buổi 2: Product Listing Tĩnh

Render danh sách sản phẩm bằng React

Học viên sẽ làm quen với cách hiển thị nhiều sản phẩm bằng component, props và map() trong React. Đây là bước quan trọng để hiểu cách React render UI từ data.

Mục tiêu

  • Hiển thị danh sách sản phẩm bằng component
  • Truyền dữ liệu qua props
  • Dùng map() để render list UI
  • Conditional rendering theo trạng thái sản phẩm
  • Tách ProductCard tái sử dụng nhiều lần

Lý thuyết

  • Props: truyền data từ component cha xuống component con
  • map(): sinh giao diện từ mảng data
  • Conditional rendering: chỉ render UI cần thiết
  • Product model: tên, giá, slug, ảnh, trạng thái
  • Format tiền + badge sale/stock
