<!DOCTYPE html>

  <head>
    <title>Trang Web</title>
  </head>
  <body>
    <h1>Xin chào!</h1>
  </body>

Thẻ Trích Dẫn và Tài Liệu Tham Khảo

"HTML là nền tảng của web. Nó cung cấp cấu trúc cho nội dung."

— Một lập trình viên web

Sách "Learning HTML & CSS" là một tài liệu tuyệt vời.

HTML được sử dụng rộng rãi trên web.

Luôn sử dụng semantic HTML là một lời khuyên tốt.

Đoạn văn (Paragraph)

Thẻ <p> được dùng để tạo các đoạn văn bản. Mỗi đoạn sẽ được tách biệt với nhau bằng khoảng cách.

Đây là đoạn thứ hai. Các đoạn có thể chứa bất kỳ nội dung nào như văn bản, liên kết, hình ảnh, v.v.

Ghi Chú (Footnote)

Bạn có thể thêm ghi chú[1] để cung cấp thông tin thêm.

Thẻ Base

Thẻ <base> (nằm trong <head>) xác định URL cơ sở và mục tiêu mặc định cho tất cả các liên kết tương đối:

<base href="https://example.com/" target="_blank">

Thẻ Meta

Thẻ <meta> được sử dụng để cung cấp thông tin bổ sung về tài liệu:

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Mô tả trang web">
<meta name="keywords" content="từ khóa 1, từ khóa 2">
<meta name="author" content="Tác giả">

Thẻ Link

Thẻ <link> được dùng để liên kết CSS:

<link rel="stylesheet" href="styles.css">

Hoặc favicon:

<link rel="icon" href="favicon.ico">

Thẻ Script

Thẻ <script> được dùng để nhúng hoặc tham chiếu mã JavaScript:

<!-- Nhúng JavaScript bên ngoài -->
<script src="script.js"></script>

<!-- Nhúng JavaScript trực tiếp -->
<script>
  console.log('Hello World!');
</script>

📋 Thuộc Tính Dữ Liệu (Data Attributes)

Data Attributes

Dùng thuộc tính <data-*> để lưu trữ dữ liệu tùy chỉnh:

  • HTML - Cấu trúc
  • CSS - Kiểu dáng
  • JavaScript - Tương tác

Các dữ liệu này có thể được truy cập bằng JavaScript: element.dataset.id
