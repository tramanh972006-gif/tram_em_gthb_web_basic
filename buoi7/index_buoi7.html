01. CSS Basics

Các thuộc tính CSS cơ bản

Đây là những thuộc tính nền tảng quan trọng nhất khi xây dựng giao diện web.

Width & Height

width dùng để xác định chiều rộng. height dùng để xác định chiều cao của element.

Box 
.box{
  width:120px;
  height:120px;
}

Margin

Margin tạo khoảng cách giữa element này với element khác hoặc giữa element với element cha. 

.box{
  margin:20px;
}

Padding

Padding tạo khoảng cách giữa nội dung bên trong và viền của element cha. 

.box{
  padding:20px;
}

Background & Color

background đổi màu nền. color đổi màu chữ. 

.box{
  background:#2563eb;
  color:white;
}

Font Styling

  • font-size → kích thước chữ
  • font-family → kiểu font
  • font-weight → độ đậm nhạt
  • font-style → in nghiêng
  • text-decoration → gạch chân/gạch ngang
.title{
  font-size:32px;
  font-family:Arial;
  font-weight:700;
  font-style:italic;
  text-decoration:underline;
}

02. Display Basic

Các dạng display cơ bản

display: block

  • Chiếm toàn bộ chiều rộng
  • Tự xuống dòng
  • Thiết lập được width/height
div{
  display:block;
}

display: inline

  • Không xuống dòng
  • Chiếm vừa đủ nội dung
  • Không set được width/height
span{
  display:inline;
}

display: inline-block

  • Nằm cùng hàng
  • Set được width/height
  • Kết hợp inline + block
button{
  display:inline-block;
}

display: none

  • Ẩn hoàn toàn element
  • Không chiếm không gian
.hidden{
  display:none;
}

03. Advanced Layout

Flexbox & Grid

display: flex

Flexbox dùng để xây dựng layout linh hoạt theo một chiều: hàng hoặc cột. 

.container{
  display:flex;
}

display: grid

Grid dùng cho layout phức tạp nhiều hàng và nhiều cột. 

.container{
  display:grid;
  grid-template-columns:
  repeat(3,1fr);
}

inline-flex

Kích hoạt flexbox nhưng element cha hoạt động như inline. 

.container{
  display:inline-flex;
}

inline-grid

Kích hoạt grid nhưng phần tử cha vẫn là inline element. 

.container{
  display:inline-grid;
}

04. Table Display

Các dạng display kiểu bảng

display: table

.container{
  display:table;
}

display: table-row

.row{
  display:table-row;
}

display: table-cell

.cell{
  display:table-cell;
}

05. Flexbox Axes

Main Axis & Cross Axis

Hướng của trục phụ thuộc vào thuộc tính flex-direction.

flex-direction Main Axis Cross Axis
row Horizontal (Left → Right) Vertical (Top → Bottom)
column Vertical (Top → Bottom) Horizontal (Left → Right)
row-reverse Horizontal (Right → Left) Vertical (Top → Bottom)
column-reverse Vertical (Bottom → Top) Horizontal (Left → Right)

06. Alignment

Các thuộc tính căn chỉnh

justify-content

Căn chỉnh theo main axis. 

.container{
  justify-content:center;
}

align-items

Căn chỉnh theo cross axis. 

.container{
  align-items:center;
}

align-content

Quản lý khoảng cách giữa nhiều dòng item khi dùng flex-wrap. 

.container{
  align-content:space-between;
}

07. Flex Grow & Shrink

Điều chỉnh kích thước item

flex-grow

Xác định item được phép giãn ra bao nhiêu. 

.item{
  flex-grow:1;
}

flex-shrink

Xác định item co lại như thế nào khi thiếu không gian. 

.item{
  flex-shrink:1;
}

Ví dụ đầy đủ

.container{
  display:flex;
}

.item-1{
  flex-grow:1;
}

.item-2{
  flex-grow:2;
}
