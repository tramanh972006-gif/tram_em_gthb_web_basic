🧠 Lý thuyết (20%)

1. SPA là gì?

SPA = Single Page Application

  • Không reload toàn bộ trang
  • Chỉ cập nhật phần nội dung cần thay đổi
  • Trải nghiệm mượt hơn

2. JSX

JSX = HTML + JavaScript 

const element = <h1>Hello React</h1>;

3. Component

Component là một phần giao diện UI độc lập có thể tái sử dụng. 

function Header() {
  return <h1>Shop của tôi</h1>;
}

4. Props

Props dùng để truyền dữ liệu từ component cha → component con. 

function ProductCard(props) {
  return <h3>{props.name}</h3>;
}

<ProductCard name="Áo" />

5. State

State là dữ liệu nội bộ của component. 

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}

⚔️ Next.js vs React Router

Next.js App Router React Router
SEO tốt Flexible hơn
SSR/SSG/ISR Client-side app mạnh
Server Components Tự kiểm soát kiến trúc
API routes Dùng với backend riêng
Phù hợp website public Phù hợp dashboard/admin

Rule of thumb

  • Public web cần SEO → Next.js
  • Dashboard/internal tool → React Router + Vite

⚛️ Các React Framework phổ biến

Next.js (App Router)

Next.js App Router là React framework tận dụng toàn bộ kiến trúc React để xây dựng full-stack React app. 

npx create-next-app@latest

Next.js được phát triển bởi Vercel.

  • Hỗ trợ SSR / SSG / ISR
  • Có thể deploy lên Node.js hoặc Docker
  • Hỗ trợ static export
  • SEO rất tốt

React Router (v7)

React Router là thư viện routing phổ biến nhất cho React.

Có thể kết hợp với Vite để tạo full-stack React framework. 

npx create-react-router@latest
  • Flexible hơn
  • Client-side app mạnh
  • Dễ custom kiến trúc
  • Phù hợp dashboard/admin

React Router được phát triển bởi Shopify.

Expo (React Native)

Expo là React framework để tạo app Android, iOS và web. 

npx create-expo-app@latest
  • Dùng cho React Native
  • Tạo app mobile native
  • Dễ build và deploy
  • Hỗ trợ Android & iOS

Expo được phát triển bởi công ty Expo.

🧩 Tư duy Component

React không viết web bằng 1 file lớn.

React chia UI thành nhiều component nhỏ. 

App
├── Header
├── ProductList
│     ├── ProductCard
│     ├── ProductCard
│     └── ProductCard
└── Footer
Nguyên tắc:
  • Mỗi phần UI = 1 component
  • Phần lặp lại → component
  • Dễ bảo trì
  • Dễ tái sử dụng

    {
      id: 1,

        />
      ))}

    </>
  );
}

🪝 React Hooks Rules

Trong React, Hooks là các hàm đặc biệt cho phép bạn sử dụng state và nhiều tính năng khác mà không cần viết class component.

📌 Mục đích của Hooks:
  • Dùng state trong function component
  • Dùng lifecycle logic dễ hơn
  • Tái sử dụng logic bằng custom hooks
  • Code ngắn gọn hơn class component

1. Không gọi Hooks trong điều kiện hoặc vòng lặp

Hooks phải luôn được gọi ở cấp cao nhất của component.

❌ Sai: 
function App() {

  if (true) {
    const [count, setCount] = useState(0);
  }

  return <h1>Hello</h1>;
}

React sẽ không đảm bảo đúng thứ tự Hooks sau mỗi lần render.

✅ Đúng: 
function App() {

  const [count, setCount] = useState(0);

  if (count > 5) {
    console.log("Count lớn hơn 5");
  }

  return <h1>{count}</h1>;
}

Hook luôn được gọi ở đầu component.

📌 Các trường hợp KHÔNG được gọi Hooks

Trường hợp Có được gọi Hooks?
if / else ❌ Không
for loop ❌ Không
while loop ❌ Không
Nested function ❌ Không
Top-level component ✅ Có

2. Chỉ gọi Hooks bên trong React Function

Hooks chỉ được gọi bên trong:

  • Function Component
  • Custom Hook
✅ Đúng: 
function Counter() {

  const [count, setCount] = useState(0);

  return (
    <button>{count}</button>
  );
}
✅ Custom Hook: 
function useCounter() {

  const [count, setCount] = useState(0);

  return {
    count,
    setCount
  };
}
❌ Sai: 
function tinhTong() {

  const [count, setCount] = useState(0);

  return count;
}

Đây chỉ là hàm JavaScript thông thường, không phải React Component hoặc Custom Hook.

🎯 Tóm tắt Rules of Hooks

  • Luôn gọi Hooks ở đầu component
  • Không gọi Hooks trong if, loop hoặc function lồng nhau
  • Chỉ gọi Hooks trong React Component hoặc Custom Hook
  • Custom Hook thường bắt đầu bằng chữ use

Ví dụ useEffect

import { useEffect } from "react";

function App() {

  useEffect(() => {
    console.log("Component mounted");
  }, []);

  return <h1>Hello React</h1>;
}
📌 Ghi nhớ:

React dựa vào thứ tự Hooks để hoạt động đúng. Nếu gọi Hooks không đúng vị trí, state có thể bị lệch hoặc gây lỗi logic.
