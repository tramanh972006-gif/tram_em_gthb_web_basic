🧩 UI Libraries & CSS Frameworks

Bootstrap

Bootstrap là gì?

Framework CSS giúp tạo giao diện nhanh bằng class có sẵn.

Ưu điểm

  • Làm giao diện rất nhanh
  • Có sẵn grid system
  • Nhiều component đẹp
  • Responsive tốt

Khi nào dùng?

Dùng khi cần làm website nhanh hoặc admin dashboard.

Ví dụ

<button class="btn btn-primary">
  Submit
</button>

Tailwind CSS

Tailwind là gì?

Utility-first CSS framework.

Ưu điểm

  • Custom giao diện rất mạnh
  • Code nhanh
  • Dễ maintain
  • Phổ biến trong React

Khi nào dùng?

Dùng khi làm React, NextJS hoặc UI hiện đại.

Ví dụ

<button class="bg-blue-500 text-white p-2 rounded">
  Submit
</button>

Ant Design

Ant Design là gì?

UI Component Library cho React.

Ưu điểm

  • Component chuyên nghiệp
  • Rất mạnh cho dashboard
  • Có sẵn table, modal, form

Khi nào dùng?

Dùng cho hệ thống quản trị và ứng dụng doanh nghiệp.

Ví dụ

import { Button } from "antd";

<Button type="primary">
  Save
</Button>

So sánh Bootstrap - Tailwind - Ant Design

Công cụ Đặc điểm Phù hợp
Bootstrap Code nhanh Website cơ bản
Tailwind Custom mạnh React hiện đại
Ant Design Component có sẵn Dashboard/Admin

🧠 Tư duy Component (Quan trọng nhất)

React không viết UI bằng 1 file lớn.

React chia giao diện thành nhiều component nhỏ. 

App
├── Header
├── ProductList
│     ├── ProductCard
│     ├── ProductCard
│     └── ProductCard
└── Footer

Nguyên tắc quan trọng

  • Mỗi phần UI = 1 component
  • Phần nào lặp lại → tạo component
  • Component giúp tái sử dụng code
  • Dễ sửa và bảo trì

Ví dụ thực tế

function Header() {
  return <h1>Shop của tôi</h1>;
}

Sử dụng component

<Header />

Ví dụ LEGO

React giống LEGO

Component = từng miếng LEGO nhỏ. Ghép lại tạo thành app lớn.

🔄 Luồng dữ liệu trong React

Data → Props → Component → UI

Giải thích

  • Data = dữ liệu
  • Props = truyền dữ liệu
  • Component = xử lý UI
  • UI = giao diện hiển thị

💻 Full React Example

function ProductCard({ name, price }) {
  return (
    <div>
      <h3>{name}</h3>
      <p>{price}</p>
    </div>
  );
}

function App() {
  return (
    <ProductCard
      name="Áo"
      price="100k"
    />
  );
}
